# مساحة Doraemon

مساحة عمل عربية مصممة للـ iPad وApple Pencil: اكتب أو ارسم أولاً، تُحفظ كل ضربة فورياً على الجهاز، ثم تُزامن الملاحظة مع مستودع GitHub خاص وتدخل صندوق تنظيم Codex عند طلبك.

## ما يعمل الآن

- رسم متجهي بالقلم مع الضغط، قلم تمييز، ممحاة، ألوان، وتراجع مستقل لكل ملاحظة.
- وضع «قلم فقط» لرفض راحة اليد، مع الحفاظ على أبعاد الرسم عند تدوير الجهاز.
- حفظ فوري في IndexedDB مع حماية من كتابة تبويب قديم، ونسخة احتياطية محلية قبل كل عملية جلب.
- إنشاء الملاحظات والمشاريع والمهام، بحث فعلي، فلاتر، تأجيل، وعرض كل العناصر.
- رفع تلقائي بعد التوقف، مع ملف مستقل لكل ملاحظة داخل `data/notes/`.
- حماية SHA تمنع جهازاً قديماً من استبدال نسخة أحدث، ودمج يحفظ النسختين عند التعارض.
- زر «أرسلها للتنظيم» يضع طلباً حقيقياً في الملاحظة كي يعالجه Codex لاحقاً.
- إعداد نشر جاهز لـ GitHub Pages عند الدفع إلى فرع `main`.

## التشغيل

```bash
npm install
npm run dev
```

وفحص نسخة الإنتاج:

```bash
npm run build
```

## مزامنة GitHub

الإعداد الافتراضي يشير إلى المستودع الخاص `annta140-bit/doraemon-workspace-data`. استخدم Fine-grained personal access token جديداً محصوراً في هذا المستودع وبصلاحية `Contents: read/write`. الرمز يُحفظ في `sessionStorage` فقط ويُحذف عند انتهاء جلسة المتصفح.

في أول اتصال من جهاز جديد اضغط **جلب ودمج بأمان** قبل أول رفع. بعد ذلك تصبح المزامنة تلقائية بعد نحو ثلاث ثوانٍ من آخر تعديل، ويمكن طلبها يدوياً أيضاً.

تُحفظ البيانات هكذا:

```text
data/
  notes/<note-id>.json
  previews/<note-id>.webp
  projects.json
  schema-v2.json
```

عندما تكون `organization.state` مساوية لـ `queued` تكون الملاحظة بانتظار Codex. عقد التنظيم الكامل موضح في [`DORAEMON_WORKFLOW.md`](DORAEMON_WORKFLOW.md).

للنشر، فعّل GitHub Pages من إعدادات المستودع واختر **GitHub Actions** كمصدر النشر. يقوم الملف `.github/workflows/deploy-pages.yml` بالباقي.

> لا تضع رمز GitHub في الكود أو المستودع العام. الرمز الذي ظهر سابقاً في محادثة يجب إلغاؤه واستبداله قبل استخدام بيانات حقيقية.
