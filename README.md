# مساحة Doraemon

مساحة عمل عربية مصممة للـ iPad والقلم: اكتب أو ارسم أولاً، يُحفظ العمل فورياً على الجهاز، ثم حوّل الملاحظة إلى مهمة أو مشروع وازامن نسخة مجمّعة مع GitHub.

## ما يعمل الآن

- رسم بالقلم واللمس مع قلم تمييز، ممحاة، ألوان، تراجع وإعادة.
- حفظ تلقائي في المتصفح بعد كل ضربة مكتملة.
- إنشاء الملاحظات، البحث، العرض الشبكي والقائمة، ومتابعة المشاريع والمهام.
- رفع وجلب `data/workspace.json` عبر GitHub Contents API.
- إعداد نشر جاهز لـ GitHub Pages عند الدفع إلى فرع `main`.

## التشغيل

```bash
npm install
npm run dev
```

وفحص نسخة الإنتاج:

```bash
npm run build
```

## مزامنة GitHub

من زر **GitHub** داخل الواجهة أدخل اسم المالك والمستودع والفرع ومسار الملف. للنسخة الأولى استخدم Fine-grained personal access token محصوراً في مستودع واحد وبصلاحية `Contents: read/write`. الرمز يُحفظ في `sessionStorage` فقط ويُحذف عند انتهاء جلسة المتصفح.

للنشر، فعّل GitHub Pages من إعدادات المستودع واختر **GitHub Actions** كمصدر النشر. يقوم الملف `.github/workflows/deploy-pages.yml` بالباقي.

> تسجيل الدخول التلقائي بحساب GitHub يحتاج GitHub App وخدمة موثوقة قصيرة لتبديل رمز التفويض؛ لا ينبغي وضع client secret أو مفتاح خاص داخل الواجهة الثابتة.
